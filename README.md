# Integrated Correctional Inmate Management System

A desktop application designed to streamline the record management, daily activities, and visitor logging for correctional facilities.

## 🚀 Features
* **Inmate Management**: Add, update, and track inmate profile records.
* **Daily Activities**: Log and monitor day-to-day events and schedules.
* **Visitor Tracking**: Record visitor information and manage visit logs.

## 🛠️ Tech Stack
* **Language**: Visual Basic (.NET)
* **IDE**: Microsoft Visual Studio
* **Database**: Local/SQL Database

## 💻 How to Run
1. Clone or download this repository.
2. Open the `.sln` file using Microsoft Visual Studio.
3. Ensure the database connection settings are configured in `App.config`.
4. Press **Start** or `F5` to build and run the system.
